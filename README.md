# Mandala vivo

Un lienzo interactivo para dibujar mandalas con simetría radial. Mientras mueves el ratón (o el dedo), el trazo se repite alrededor del centro y cambia de color de forma continua.

## Cómo usarlo

No necesita instalación ni dependencias. Abre `index.html` en cualquier navegador moderno y dibuja manteniendo pulsado el botón del ratón.

## Controles

| Control | Qué hace |
|---|---|
| **Ejes** | Número de repeticiones radiales del trazo (de 2 a 16). |
| **Grosor** | Grosor de la línea (de 1 a 12). |
| **Espejo** | Activa o desactiva la simetría especular en cada eje. |
| **Borrar** | Limpia el lienzo. |
| **Guardar PNG** | Descarga el dibujo como `mandala.png`. |
